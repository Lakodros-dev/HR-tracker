# Loyiha Fayllari

## Asosiy Fayllar

### Bot
- `bot.py` - Asosiy bot
- `database.py` - SQLite database
- `config.py` - Konfiguratsiya
- `utils.py` - Yordamchi funksiyalar

### Modullar
- `scheduler_tasks.py` - Avtomatik vazifalar (ertalab, tushlik, kechqurun)
- `employee_management.py` - Hodimlarni boshqarish (ro'yxatdan o'tish, tasdiqlash)
- `work_time_tracker.py` - Ish vaqti kuzatuvi (kechikish, statistika)
- `settings_manager.py` - Sozlamalarni boshqarish (backend dan)
- `admin_settings.py` - Admin sozlamalari
- `mini_app_handler.py` - Mini app handler

### Mini App (Alohida Deploy)

- Backend: https://map-for-marking-domain-1.onrender.com

### Sozlamalar
- `.env` - Environment variables (BOT_TOKEN, ADMIN_ID, etc.)
- `settings.json` - Bot sozlamalari (ish vaqti, ofis hududi, etc.)
- `requirements.txt` - Python dependencies

### Database
- `attendance.db` - SQLite database (avtomatik yaratiladi)

### Qo'llanmalar
- `README.md` - Asosiy qo'llanma
- `QUICK_START.md` - Tezkor boshlash
- `.gitignore` - Git ignore
